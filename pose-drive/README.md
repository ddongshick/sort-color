# 포즈 드라이브 · micro:bit

Teachable Machine의 **포즈 프로젝트**로 학습한 몸짓을 마이크로비트 자동차의 움직임으로 연결하는 교사 연수용 웹앱입니다.

**공개 웹앱: https://ddongshick.github.io/sort-color/pose-drive/**

참가자는 GitHub나 ChatGPT에 로그인하지 않고 웹앱 주소로 접속할 수 있습니다. 서버 설치 없이 브라우저에서 동작합니다.

## 준비물

- 카메라와 블루투스가 있는 PC, Chrome 또는 Edge
- 블루투스 UART 수신 및 모터 제어 프로그램이 들어 있는 마이크로비트 자동차
- Teachable Machine에서 학습하고 업로드한 **포즈 모델** 주소
- 모델을 불러올 때 사용할 인터넷 연결

## 참가자 사용 순서

1. 공개 웹앱을 Chrome 또는 Edge의 새 탭에서 엽니다.
2. 포즈 모델 주소를 입력하고 **모델 불러오기**를 누릅니다. 예시 모델 주소가 기본으로 들어 있습니다.
3. 카메라 사용을 허용합니다.
4. **포즈와 명령 연결**에서 각 클래스에 전진·후진·좌회전·우회전·정지 중 원하는 동작을 지정합니다.
5. 자동차 전원을 켜고 **마이크로비트 연결**을 누른 뒤 자신의 `BBC micro:bit` 기기를 선택합니다.
6. 처음에는 바퀴를 들어 올린 상태로 수동 방향 버튼을 눌러 방향과 정지를 확인합니다.
7. **포즈 운전 시작**을 누르고 학습한 포즈를 유지합니다.
8. 멈추려면 **즉시 정지** 또는 **Esc**를 누릅니다. 다시 움직이려면 포즈 운전을 다시 시작합니다.

다른 참가자들은 각자 자기 PC에서 모델과 자동차를 연결합니다. 웹앱은 공용이지만 카메라·연결·매핑 설정은 각 브라우저에서 따로 동작합니다.

## 연수 활동 예시

1. **몸짓 정하기:** 전진·후진·좌회전·우회전·정지에 사용할 서로 구분되는 포즈를 정합니다.
2. **데이터 모으기:** Teachable Machine에서 포즈 프로젝트를 만들고, 여러 사람이 거리와 각도를 바꿔 예시를 수집합니다. 편하게 서 있는 자세를 정지 클래스로 학습해 보세요.
3. **학습하고 연결하기:** 모델 내보내기 → 업로드를 완료한 뒤, 모델 주소를 웹앱에 넣고 각 클래스의 자동차 명령을 지정합니다.
4. **시험하고 개선하기:** 조명·배경·사람·거리를 바꾸어 보고 잘못 인식하는 상황을 찾아 데이터를 보강합니다. 다시 학습·업로드한 뒤 웹앱에서 모델을 다시 불러옵니다.

클래스 이름은 자유롭게 정해도 됩니다. `F`, `B`, `L`, `R`, `STOP`이나 ‘전진’, ‘후진’ 등 명확한 이름은 자동 연결하고, 모르는 이름은 **정지**로 시작합니다. 모든 참가자가 자신의 매핑을 확인한 뒤 운전을 시작하세요.

## 자동차 코드와 맞는 신호

모든 명령은 UTF-8 문자열 뒤에 줄바꿈 `\n`을 붙여 블루투스 UART로 보냅니다.

| 명령 | 자동차 동작 |
| --- | --- |
| `F` | 전진 |
| `B` | 후진 |
| `L` | 좌회전 |
| `R` | 우회전 |
| `STOP` | P0·P1 모터 정지, 소리·LED 초기화 |
| `A` | P2 보조 서보 |
| `C` | 웃음소리 |
| `D` | 하트 표시 |

제공된 자동차 코드에는 `B` 조건이 두 번 있으므로 두 번째 보조 서보 분기는 실행되지 않습니다. 이 앱에서 `B`는 후진으로 사용합니다. `A/C/D`는 주행 모터를 멈추지 않는 명령이어서 앱이 먼저 `STOP`을 보냅니다.

## 인식과 정지 방식

- 기본 인식 기준: 확률 **85%**, 같은 포즈 **0.25초 유지**. 화면에서 조정할 수 있습니다.
- 자세를 놓치거나 현재 명령이 더 이상 확인되지 않으면 정지합니다. 기준 시간은 **450ms**이며 브라우저 처리와 블루투스 전송 지연은 추가될 수 있습니다.
- 정지 버튼, Esc, 창 전환, 탭 숨김, 카메라 중단, 매핑·인식 설정 변경은 포즈 운전을 해제합니다.
- 인식만 일시적으로 놓친 경우에는 정지 후 새로운 안정된 포즈에 다시 반응합니다.
- 수동 방향 버튼과 방향 키/WASD는 누르는 동안 움직입니다. 입력란을 편집 중일 때 방향 키·스페이스는 입력에 사용합니다.
- 브라우저나 PC가 완전히 멈추면 웹앱이 정지 신호를 보낼 수 없습니다. 제공된 자동차 코드는 블루투스 연결 해제 시 정지하지만, 수신 시간 초과 감시 기능은 없습니다.

## 자주 생기는 문제

| 상황 | 확인할 내용 |
| --- | --- |
| 모델을 불러오지 못함 | 이미지 프로젝트가 아닌 **포즈 프로젝트**인지, 업로드를 완료했는지, 주소가 맞는지 확인합니다. |
| AI 도구 다운로드 실패 | 인터넷 및 학교 네트워크의 `cdn.jsdelivr.net` 접근 여부를 확인합니다. |
| 카메라가 켜지지 않음 | 브라우저 카메라 권한과 다른 프로그램의 카메라 사용 여부를 확인합니다. |
| 자동차가 목록에 없음 | PC 블루투스, 자동차 전원과 UART 프로그램, 다른 PC에 연결되어 있는지 확인합니다. |
| 자동차는 연결됐는데 움직이지 않음 | 포즈별 명령이 모두 정지인지, 포즈 운전을 시작했는지, 인식 확률이 기준에 도달하는지 확인합니다. |
| 반응이 너무 빠르거나 불안정함 | 인식 확률 기준이나 포즈 유지 시간을 높이고 학습 데이터를 보강합니다. |

## 영상과 저장

카메라 영상과 포즈 인식은 브라우저 안에서 처리하며 앱 서버에 영상을 저장하거나 전송하지 않습니다. 모델·라이브러리를 다운로드하기 위한 인터넷 요청은 발생합니다. 포즈별 명령 설정은 이 브라우저에 모델 주소별로 저장합니다. 이 버전에는 오프라인 모델 저장 기능이 없습니다.

## 개발 및 재사용

`index.html`, `styles.css`, `app.mjs`, `control.mjs`가 웹앱 파일입니다. 이 네 파일을 같은 폴더에 두고 HTTPS 정적 호스팅에 배포하면 됩니다. `.openai` 설정이나 ChatGPT 로그인에 의존하지 않습니다.

현재 공개 경로는 이 저장소의 `main` 브랜치 `pose-drive/` 폴더입니다. 기존 색상 분류기는 저장소 루트에서 별도로 동작합니다.

```sh
cd pose-drive
node --check app.mjs
node --check control.mjs
node --experimental-vm-modules --test tests/*.test.mjs
```

모델 실행에는 `@tensorflow/tfjs@1.3.1`, `@teachablemachine/pose@0.8.3`을 사용합니다. `estimatePose()` 후 `predict()`를 호출합니다. 공식 API: https://github.com/googlecreativelab/teachablemachine-community/tree/master/libraries/pose
